# WINK PLAY

넷플릭스와 같은 OTT 서비스를 참고해서 제작하는 웹 프로젝트입니다.
추천작품과 인기작품을 확인하고, 원하는 작품을 검색하거나 찜할 수 있는 페이지를 만드는 것이 목표입니다.

## 1주차 구현 내용

- HTML 기본 구조 작성
- header, nav, main, section, article, footer를 활용한 페이지 구조 구성
- 추천 작품 영역 구현
- 인기 작품 카드 3개 구현
- 각 작품에 재생 / 찜 버튼 추가
- 작품 검색 form 구현
- 찜한 작품 영역 추가
- 이미지와 alt 속성 적용

## 다음 주 계획

2주차에는 CSS를 활용해 전체 레이아웃과 디자인을 적용할 예정입니다.
인기 작품 카드들을 가로로 배치하고, 버튼과 여백, 이미지 크기 등을 조절해서 OTT 서비스 느낌이 나도록 화면을 구성해볼 계획입니다.
