# WINK PLAY

> 보고 싶은 작품을 고르고, 찜하고, 바로 재생하는 WINK만의 OTT 웹사이트 (가안)

WINK PLAY는 넷플릭스처럼 영화와 시리즈를 한눈에 둘러보고, 마음에 드는 작품을 찜해 두었다가 다시 찾아볼 수 있는 OTT 웹사이트입니다. 4주 동안 HTML → CSS → JavaScript → 데이터와 배포 순서로 조금씩 완성해 나갑니다.

## 서비스 소개

- 메인 화면에서 **추천 작품**을 크게 보여주고, 바로 재생하거나 찜할 수 있습니다.
- **홈 / 영화 / 시리즈 / 찜** 메뉴로 작품을 종류별로 둘러볼 수 있습니다.
- **검색창**에 제목을 입력해 원하는 작품을 찾을 수 있습니다.
- 작품 카드를 눌러 **상세 정보**를 확인하고, **찜 목록**과 **마이페이지**에서 내 취향을 관리할 수 있습니다.

## 1주차 구현 범위

이번 주에는 CSS와 JavaScript 없이 **HTML만으로 화면의 구조**를 만들었습니다. 꾸미지 않았으니 못생긴 게 정상입니다.

- [x] `index.html`, `README.md`, `images/` 폴더 생성
- [x] `DOCTYPE`, `html lang="ko"`, `head`, `body`, `meta viewport`, `title`
- [x] `header`, `nav`, `main`, `section`, `footer`로 큰 구조 나누기
- [x] 헤더에 WINK PLAY 로고, 메뉴 4개(홈 / 영화 / 시리즈 / 찜), 프로필 버튼 영역
- [x] 추천 작품 `section`에 `h1`, 소개 문장, 재생 버튼, 찜 버튼
- [x] 작품 카드 4개를 `article`로 작성 (이미지, 제목, 장르, 짧은 설명)
- [x] 모든 이미지에 의미 있는 `alt`
- [x] 작품 검색 `form`에 `label`과 `input` 연결

## 다음 주 계획 (2주차 CSS)

- 어두운 배경에 밝은 글씨를 쓰는 OTT 분위기로 색상과 글꼴 정리
- 추천 작품 영역을 큰 배경 이미지 위에 글이 올라간 형태로 배치
- 작품 카드를 Flexbox로 가로로 나열하고, 마우스를 올리면 살짝 커지는 효과
- 화면이 좁아지면 메뉴와 카드 배치가 바뀌는 반응형 레이아웃

## 실행 방법

1. 이 저장소를 clone 하거나 다운로드합니다.
2. `index.html`을 더블클릭해 브라우저로 엽니다. 별도 설치가 필요 없습니다.
